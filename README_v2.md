# CG Final Project — Vector Graphics Studio v2.0

A more advanced 2D vector drawing application built with Python + PyOpenGL + GLUT.

## New features
- Toolbar UI
- Line / Rectangle / Circle / Ellipse
- Polygon / Star / Bézier
- Scanline polygon filling
- De Casteljau Bézier algorithm
- Mouse selection and dragging
- Translation / scaling / rotation
- Undo / Redo
- Duplicate / Delete
- Grid and snap-to-grid
- Zoom and pan
- Color palette
- Layer panel
- Save / Load as JSON

## Run
```bash
pip install -r requirements.txt
python vector_draw_tool_v2.py
```

## Keyboard shortcuts
- V: Select
- L: Line
- R: Rectangle
- C: Circle
- E: Ellipse
- P: Polygon
- A: Star
- B: Bézier
- F: Toggle fill
- G: Grid
- N: Snap
- U: Undo
- Y: Redo
- Q: Duplicate
- D: Delete
- [ / ]: Rotate
- + / -: Scale
- Arrow keys: Move selected object
- Mouse wheel: Zoom
- Middle mouse drag: Pan
- Enter: Finish polygon
- Esc: Exit
